# Weighted_Moving_Average

Weighted Moving Average (WMA) assigns more importance to recent price data by applying weights to each data point in the moving average window. This makes WMA more responsive to price changes than Simple Moving Average (SMA), while still smoothing out short-term fluctuations.

## Applications

- Trend detection  
- Entry/exit signals  
- Emphasizing recent price movements  
- Backtesting strategies  
- Use shorter windows (e.g., 10 or 20 period) for faster reaction  
- Combine with other indicators (e.g., RSI, MACD) for confirmation  
- Avoid using WMA alone in volatile or sideways markets

## Notes

- WMA is more sensitive than SMA but less volatile than EMA  
- Works well for swing trading and short-term analysis  
- high-quality price data
